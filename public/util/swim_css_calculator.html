🏊‍♂️ 수영 CSS 계산기

[ CSS 계산 공식 ]
CSS (m/sec) = (400 - 200) / (T400 - T200)
CSS의 의미: Critical Swim Speed (CSS) 임계 수영 속도는 단순히 스피드를 측정하는 것이 아니라, 거리가 늘어남에 따라 페이스가 얼마나 떨어지는지를 분석하여 '피로 없이 지속 가능한 유산소 속도'를 찾아내는 지표입니다.
※ 400m와 200m의 기록 차이가 커질수록(즉, 200m는 매우 빠른데 400m가 느릴수록) 당신의 지속가능한 속도는 단거리 능력에 비해 낮게 평가됩니다. 💡 팁: 200m 기록은 400m 기록의 약 45~48% 수준이 적당합니다.

200m 전력주 기록03:44
